# Delta Type
Независимый плагин статистики печати, Node.js 22+. `npm ci`, `.env.example` → `.env`, `npm start`.

Токен плагина должен иметь **имя `dev.delta.type`** и scopes `register:typing`, `call:storage.write`. Для тренажёра выдайте отдельный токен с `call:typing.ingest`. Откройте `http://127.0.0.1:7720`, введите токен и явно наберите текст в поле.

WPM = символы / 5 / минуты; показатель `accuracy` — доля без исправлений, а не точность относительно эталонного текста. Раздельно RU/EN. Содержимое, клавиши, пароли, заголовки окон НЕ передаются. IME в тренажёре не поддерживается. Нет скрытого глобального перехвата клавиатуры; для системного сбора подключите клиент, отправляющий только строгую схему `typing.ingest`. Android/Wayland/macOS глобальные сборщики не входят в этот плагин.

Агрегаты попадают в дисковую очередь (файлы 0600, каталог 0700), повторно отправляются в `STORAGE_COMPONENT.write`; UUID/время сохранены, storage дедуплицирует запись. Лимит очереди 10000 записей, последние 10000 session IDs дедуплицируются. При переполнении возвращается ошибка, не молчаливое удаление. `typing.settings` admin-only выключает сбор; `typing.flush` отправляет очередь. `npm test`.
